## Code, Git & preview

### playground/07-code-editor.png

Code editor — browse the project tree, open files, and edit the codebase in the workbench.

### playground/08-git-history-graph.png

Git in the workbench — commit history, author commits yourself or via AI, and explore the repo graph.

Live Preview — AI chat starts your website or app inside the project sandbox; the Preview tab streams it live with no extra host setup. Same seamless flow on a laptop or hosted Everflow.
