## PatternFly Components Used

The project uses native PatternFly UI Kit components supplemented with Shadcn/ui and custom components:
- `Card`, `CardTitle`, `CardBody`, `CardFooter`
- `Button`, `ButtonVariant`
- `Badge`
- `Avatar`, `AvatarGroup`
- `Table`, `Thead`, `Tbody`, `Tr`, `Th`, `Td`
- `Tabs`, `Tab`, `TabContent`
- `Progress`, `ProgressSize`, `ProgressVariant`
- `Select`, `SelectOption`, `SelectVariant`
- `SearchInput`
- `Pagination`
- `EmptyState`, `EmptyStateIcon`, `EmptyStateBody`
- `LoginPage`, `LoginForm`, `LoginFooterItem`
- Charts from `@patternfly/react-charts`

**Additional Libraries**:
- **ReactFlow** (`@xyflow/react`): Visual workflow builder and node-based editor
- **TanStack Query** (`@tanstack/react-query`): Data fetching and caching
- **React Hook Form** + **Zod**: Form validation and management
- **Recharts**: Data visualization charts
- **Lucide React**: Icon library
- **Tailwind CSS**: Utility-first CSS framework
- **Sonner**: Toast notifications
- **Vaul**: Drawer component
- **cmdk**: Command menu component
- **date-fns**: Date utility library
- **embla-carousel-react**: Carousel component
- **react-day-picker**: Date picker component
- **react-resizable-panels**: Resizable panel layouts

**Custom Components**:
- `collapsible-page-header.tsx`: Auto-hide header on scroll
- `compact-page-header.tsx`: Manual compact header toggle
- `PageHeader.tsx`: Consistent page header component
- `IssuesTab.tsx`: Issue tracking interface
- `PullRequestsTab.tsx`: Pull request management
- `WorkflowTab.tsx`: Visual workflow designer
- `AIEditorTab.tsx`: AI-assisted code editing
- `FileManagerTab.tsx`: File system operations
- `ContainerLogsTab.tsx`: Container log viewer
- `WebtopTab.tsx`: Workspace viewer with lifecycle controls
- `WorkspaceOrchestration.tsx`: Service orchestration interface
- `ProjectDetailsTab.tsx`: Project configuration
- `RepositoryGitTab.tsx`: Git operations
- `SafetyComplianceTab.tsx`: Compliance settings
- `ProjectCreationWizard.tsx`: New project wizard
- `AuthGuard.tsx`: Route protection component
- `CreateWorkflowDialog.tsx`: Workflow creation dialog
- `PersonaSelector.tsx`: Chatbot persona selection
- `ChatInterface.tsx`: AI chat interface
- `ModelSettings.tsx`: LLM configuration settings
- `TemplateManager.tsx`: Prompt template management
