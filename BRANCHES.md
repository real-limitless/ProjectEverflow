# Branches

Source: private kit TheFLOW (`real-limitless/TheFLOW`). Do not fork these rules here.

Everflow does not use the shared campaign chrome. It still uses this branch model.

| Branch | Audience | What is on it |
| --- | --- | --- |
| `CORE` (this branch) | Everyone | Concept, methodology, install pointers. No application source. |
| `Development-Everflow` | Operators and developers | Runnable platform. Same role as `DEVELOPMENT` on sibling repos. Rename later. |

If you only see markdown, you are still on `CORE`.

```sh
git checkout Development-Everflow
```
