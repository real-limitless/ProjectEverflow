# Everflow toolkit — Mobile (Expo / React Native)

Pick-up-ready Expo app for iOS and Android, with **web** enabled so Everflow Preview can show your UI inside phone/tablet device frames.

## In Everflow

1. Create a project from **iOS app (React Native)** or **Android app (React Native)**.
2. In the sandbox Terminal: `npm install && npm run web`
3. Open **Preview**, pick a device (iPhone 12, Pixel 7, Galaxy Z Fold, iPad, …).

Device frames iframe Expo web — they are not Xcode Simulator or Android Emulator.

## Local

```bash
npm install
npm run web
```

Open http://localhost:8081
